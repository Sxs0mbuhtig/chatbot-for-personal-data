## Strict Execution Guardrails for Antigravity

1. **Low Offload Thresholds:**
   - **Code / Schema:** Any code output, JSON schema definition, or script exceeding 5 lines MUST be generated by calling local HAProxy (`http://127.0.0.1:11435`).
   - **Text / Etymological Analysis:** Any explanation, etymological report, or documentation exceeding 20 words MUST be generated by calling local HAProxy (`http://127.0.0.1:11435`).

2. **Cloud Prose Suppression Directive:**
   - Do NOT summarize, explain, or echo local outputs unless explicitly requested.
   - Pass local Ollama responses directly through to the user interface.
   - Keep Cloud API response bodies under 30 words total per turn.

3. **Error & Fallback Handling:**
   - If a local MCP call fails, retry locally once or report the failure in a 1-line error message.
   - NEVER fall back to generating the full missing payload directly via Cloud API.
